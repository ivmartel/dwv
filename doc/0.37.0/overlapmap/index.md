# OverlapMap

<SourceLink href="/source/src/image/masksegmenthelper-js/#L216" label="maskSegmentHelper.js:216" />

An Dictionary containing the count of overlapping voxels between two sets of segments. The key is the segment number of a segment in the first set. The value is a Dictionary of all of the segments in the second set that overlap with the key segment.

**Type**

`Record.<number, `[`Overlap`](/overlap)`>`
