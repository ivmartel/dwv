DICOM SR

The DICOM SR strucutre used to store annotations is based on the 'DICOM SR for communicating planar annotations' document from David A. Clunie (ref).

SCOORD items are translated according to their Graphic Type ((0070,0023) see part03/sect_C.18.6):

  • Point -> Point2D

  • Multipoint: not used

  • Polyline ->

    • Line: if open shape and 2 points
    • Protractor: if open shape and 3 points
    • Rectangle: if closed shape with 5 points that form 4 perpendicular lines
    • ROI: if closed shape and not rectangle

  • Circle -> Circle

  • Ellipse -> Ellipse

Closed shapes are polylines that have the same point as first and last item in their point list.

DWV uses the Comprehensive 3D SR IOD since it allows for the usage of the SCOORD3D value type.

TID 1500 format

TID 1500 is the root template for a "Measurement Report". It consists of one "Imaging Measurements" container including (1-n) "Measurement Group". Measurement Groups can follow TID 1410 "Planar ROI Measurements and Qualitative Evaluations" or TID 1501 "Measurement and Qualitative Evaluation Group".

SR documents following TID 1500 include the root tag (0040,A504) "Content Template Sequence" attribute containing an item with (0008,0105) "Mapping Resource": “DCMR” and (0040,DB00) "Template Identifier": “1500”.
