# OverlapCount

<SourceLink href="/source/src/image/masksegmenthelper-js/#L194" label="maskSegmentHelper.js:194" />

The overlap count of a single segment with another segment.

**Properties**

- `label` (string) — The segment label.
- `count` (number) — The number of overlapping voxels.
- `percentage` (number) — The overlap percentage between 0 and 100.
