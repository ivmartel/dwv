# TimeObj

<SourceLink href="/source/src/dicom/dicomdate-js/#L23" label="dicomDate.js:23" />

Time object.

**Properties**

- `hours` (number) — The hours number.
- `minutes` (number) — The minutes number.
- `seconds` (number) — The seconds number.
- `milliseconds` (number) — The milliseconds number, can be fractional (DICOM TM has a microsecond precision).

**Type**

`object`
